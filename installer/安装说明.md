# 句听 Windows 安装版

双击文件名以“句听-安装程序-v”开头的 EXE，选择安装位置，按提示安装。安装包包含本地英语识别模型，无需安装 Python 或填写 API Key。系统需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。

默认程序位置：`%LOCALAPPDATA%\Programs\Juting`。

请通过桌面或开始菜单中的“句听”启动。快捷方式把学习数据保存在 `%LOCALAPPDATA%\Juting\data`，与程序文件分开。卸载程序保留这个数据目录；重新安装后通过快捷方式启动可继续使用记录。

安装版不包含个人音频和学习记录，也不打包剑桥音频。进入程序后可导入音频，或者从剑桥听力库按需下载。

## 从原便携版迁移

1. 完全关闭原便携版和安装版。
2. 首先备份原便携版旁边的整个 `data` 文件夹。
3. 如果安装版已有记录，也先备份 `%LOCALAPPDATA%\Juting\data`。
4. 首次迁移到空白安装版时，把原来的整个 `data` 文件夹复制到 `%LOCALAPPDATA%\Juting\data`。两个版本都有记录时不要直接覆盖；先分别保留备份。
5. 从桌面快捷方式打开安装版，检查课程及听写记录。

## 构建

先使用 `tools/build_windows.py` 生成暂存版，再运行 `python tools/build_installer.py --iscc "Inno Setup 6 安装目录\ISCC.exe"`。脚本生成中文界面消息并编译安装程序。编译结果位于 `outputs`。发布安装包放 GitHub Releases；上传源码时包含 `installer/` 和 `tools/build_installer.py`，不要把模型或安装包提交到源码仓库。
